# Comments in your voice — template

Copy to `prompts/comment-voice.md` and replace the examples with two or three
comments you would actually post. The real file is gitignored, like
`prompts/voice.md`. Once you have posted a few comments from the dashboard, the
latest ones you posted are shown to the drafter as well, so this file only has to
carry it until then.
